Política de Privacidade

Última atualização: 12 de novembro de 2026

Esta Política de Privacidade explica como o MusicFlow Local utiliza informações quando o usuário conecta uma conta Google ou um canal do YouTube ao aplicativo.

1. Sobre o aplicativo

O MusicFlow Local é um aplicativo executado localmente no computador do usuário. Sua finalidade é auxiliar na organização de arquivos de mídia, na produção de vídeos e no envio de conteúdo para canais do YouTube que o usuário autoriza.

2. Dados acessados

Com o consentimento do usuário, o MusicFlow utiliza a API do YouTube e o OAuth 2.0 do Google para obter permissões necessárias ao envio e gerenciamento dos vídeos solicitados. Durante essa operação, o aplicativo pode processar identificadores de vídeos, respostas da API, tokens de acesso e de atualização, informações de publicação, títulos, descrições e imagens de miniatura.

3. Como os dados são utilizados

As informações e permissões fornecidas são utilizadas para autenticar o usuário, enviar vídeos e miniaturas, configurar detalhes de publicação e acompanhar o resultado das operações solicitadas. O aplicativo não solicita acesso para vender ou compartilhar dados de contas Google com anunciantes.

4. Armazenamento local

O MusicFlow mantém dados de configuração, histórico de operações e credenciais OAuth necessários ao funcionamento em arquivos locais do computador onde é executado. Esses dados não são hospedados por este site institucional. O usuário deve proteger o acesso ao seu computador e aos arquivos de autenticação.

5. Serviços de terceiros e conexões

Para usar as funcionalidades do YouTube, o aplicativo envia requisições aos serviços do Google. Quando o usuário configura voluntariamente um servidor proxy, parte dessas conexões pode passar pelo provedor de proxy escolhido. O tratamento de dados pelos serviços externos também está sujeito às respectivas políticas de privacidade.

6. Controle, revogação e exclusão

O usuário pode desconectar um canal no aplicativo, remover os dados locais relacionados à autenticação ou revogar o acesso concedido na página de conexões da Conta Google. A remoção de dados locais não exclui automaticamente vídeos já enviados ao YouTube; esses vídeos devem ser administrados no YouTube Studio.

7. Segurança

As comunicações com as APIs do Google utilizam HTTPS. A segurança do armazenamento local também depende das medidas de proteção adotadas no dispositivo do usuário. Nenhum sistema pode garantir segurança absoluta.

9. Alterações nesta política

Esta política poderá ser atualizada caso as funcionalidades ou práticas de tratamento de dados do aplicativo sejam alteradas. A versão vigente será publicada nesta página.

10. Uso de dados das APIs Google

O uso e a transferência de informações recebidas das APIs Google são destinados exclusivamente às funcionalidades descritas nesta política e devem respeitar a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos aplicáveis de uso limitado.
